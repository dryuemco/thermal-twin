### Novelty verdict

- **Potentially new:** the exact benchmark implementation; the paired, replicated evidence that a validation procedure selects models whose advantage disappears on later burning; quantification of validation-estimation errors across these landscapes.
- **Incremental:** requiring fire-history density as a susceptibility comparator; assembling temporal and geographic hold-outs into a reproducible protocol.
- **Not new:** historical-frequency references, smoothed historical references, reference-relative skill, temporal hold-outs, location-only controls, or critiques of random/spatial validation.

Avoid claiming “the first persistence-referenced fire evaluation,” “the first temporal validation of susceptibility,” “spatial CV is unbiased,” or “machine learning cannot beat fire history.”

Your novelty sentence is defensible **as a description**, not as a priority claim. I would replace “persistence” with **“historical fire-density reference”** where precision matters: a multiyear density surface is closer to spatial climatology than strict last-state persistence.

**Estimated EMS novelty: modest, roughly 2–3/5.** The ingredients are established. Publication value would come from unusually convincing evidence, a reusable implementation, and a clearly specified evaluation problem. Thirty-one landscapes alone do not supply methodological novelty.

## Code issues

**I cannot report a verified bug or certify leakage absence in `protocol_dev.py`.** The following are required audit conditions, not observations about its implementation.

| Component | Required condition |
|---|---|
| **Out-of-group calibration** | For an evaluation group, supervised calibrator fitting and model selection exclude that entire geographic group, including overlapping landscapes. Access to its historical fire map may be permissible if that is part of the declared deployment information set; that is different from learning from its evaluation labels. |
| **Earlier-years-only calibration** | Calibration outcomes must be fully observed and available before the prediction issue date. Checking `calibration_year < test_year` is insufficient when label windows span multiple years. |
| **Nested score generation** | Calibrators should learn from appropriately held-out predictions. Fitting them to optimistic training predictions can distort future calibration even when the final test labels are excluded. |
| **Label windows** | Verify exact start/end dates, inclusivity, focal-event exclusion, missing-data masks, product latency, and whether cross-year fires are assigned consistently. Missing coverage must remain missing. |
| **G-B horizon** | Calibration labels must have the same horizon as G-B. An annual probability cannot be compared directly with an “any burn over several years” label. Conversion requires explicit assumptions. |
| **G-C label** | Verify whether the target is focal-event membership, subsequent burning, or any burning. Those support different claims. Reusing the focal event would not establish future susceptibility. |
| **R1 construction** | Every historical burn contributing to a score must precede its issue date. Inspect cached rasters, normalization, bandwidth selection, edge handling, and joins—not just the final year filter. |
| **Calibration fairness** | Apply comparable calibration opportunities to R1 and competitors. Any clipping, smoothing, isotonic fitting, or prevalence adjustment must be chosen without evaluation labels. |
| **Sampling prevalence** | Balanced case-control predictions are not automatically population probabilities. Proper-score calculations need representative evaluation data or justified weights and calibration. |
| **Honesty estimates** | Compute validation-minus-later-performance on matched model/site/horizon units. Report both signed and absolute errors; bootstrap the paired contrasts. Separately evaluate the performance of the **model selected by each validation procedure**. |
| **Degenerate cases** | One-class site-years have undefined AUC. Report exclusions and their consequences rather than silently dropping them. Check ties, nonfinite probabilities, clipping, duplicate keys, and row alignment. |

The highest-value verification is a small synthetic audit where excluded-group labels, future labels, and post-cutoff inputs are altered deliberately: earlier permissible predictions must remain unchanged. Also manually reconstruct several score/label pairs at window boundaries.

## Verdict and minimum changes

**I would not sign off on the current framing for submission.** That is a judgment about unresolved design and evidence requirements, not a finding that the unseen code is defective.

The minimum changes are:

1. **Establish the target:** independently validate wildfire versus other burning, or narrow the terminology.
2. **Audit temporal provenance and code:** calibration, historical windows, input release dates, G-B/G-C definitions, and missing coverage.
3. **Freeze the remaining blind evaluation:** include stopping rules, reference choice, model set, margins, aggregation, and exclusions.
4. **Strengthen the comparison:** add a credible environmental model and an R1-plus-environment model.
5. **Repair inference and language:** cluster-aware paired uncertainty, equivalence bounds where warranted, and absolute as well as signed validation errors.
6. **Resolve chronology:** document 11.4 provenance and separate retrospective geographic testing from forward prediction.

I would reframe the paper around **incremental predictive value beyond historical fire density**, with the validation diagnosis as supporting evidence. Keep TMA/TMA-cell secondary unless they provide an independently justified methodological contribution.

A safer title is: **“Evaluating wildfire susceptibility beyond historical fire density across 31 Mediterranean landscapes.”**

The defensible headline is: **“Under the specified information set and evaluation horizons, the tested models did not demonstrate additional predictive value over historical fire density.”** Whether the repository supports even that statement remains to be audited.
